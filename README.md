## Featured Work

### Sudeshi Code Review

An AI-assisted code review CLI for TypeScript and JavaScript repositories, combining deterministic code checks with optional AI-powered analysis.

- 🔍 Scans repositories for potential security issues using deterministic rules
- 🛡️ Detects patterns such as dangerous HTML rendering, hardcoded credentials, and unsafe JavaScript URLs
- 🤖 Integrates optional Sarvam AI review for additional analysis
- 📝 Generates Markdown reports with severity levels and supporting evidence
- 🧪 Built with TypeScript, automated tests, and a packaged CLI workflow

👉 [GitHub Repository](https://github.com/sriram23/sudeshi-code-review) · [npm Package](https://www.npmjs.com/package/sudeshi-code-review)

### Sudeshi AI Chat

A multilingual AI chat application built with Next.js, designed around real-time streaming, provider abstraction, conversation memory, and frontend performance.

- ⚡ Implemented real-time AI response streaming using SSE
- 🔄 Built asynchronous workflows for reliable streaming interactions
- 🚀 Optimized large chat histories using virtualization and memoization
- 🧠 Implemented token-aware conversation memory and summarization
- 📊 Added streaming metrics including time to first byte (TTFB) and tokens/sec
- 🔌 Designed a provider abstraction for integrating different AI backends

👉 [GitHub Repository](https://github.com/sriram23/sudeshi-ai-chat) · [Live Demo](https://sudeshi-ai-chat.vercel.app)
